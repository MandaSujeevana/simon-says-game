# 🎮 Simon Game

A browser-based memory game built using **HTML, CSS, and JavaScript**. The game challenges players to remember and reproduce an increasingly complex sequence of colors and sounds.

## ✨ Features

- 🎯 Random sequence generation
- 🧠 Progressive difficulty
- 🔊 Interactive sound effects
- 🎨 Visual feedback for user actions
- 🏆 Score and level tracking
- 📱 Responsive interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Start the game.
2. Watch the sequence of colors carefully.
3. Repeat the sequence by clicking the buttons in the correct order.
4. Each successful round increases the difficulty.
5. The game ends when an incorrect sequence is entered.
